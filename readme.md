
# Deals Finder Agent

This module uses the most performing AI price predictor from [NEGU LLM Regressor](https://github.com/NEGU93/llm_regression) project to find good deals and prices.

## Running code

0. Create a `.env` with the open AI and Hugging Face tokens.
1. Download the database from [HF](https://huggingface.co/datasets/NEGU93/pricer-data) and create the Schema DB from the `python -m src.create_db` (all in one step)
2. Run all



> [!tip]
> You can run each agent indivisually for testing porpuses
